IMPORTANT: Topic Declaration Image Required

The thesis requires a topic-declaration image file to be placed in the thesis/images/ directory.

Supported formats: PNG, JPG, JPEG

## Image Size Options

The main.tex file has 3 options for image scaling:

### Option 1: 1.2x Scale (Default - Currently Active)
```latex
\includegraphics[width=1.2\textwidth,height=1.2\textheight,keepaspectratio]{topic-declaration.png}
```
Good for most cases - makes image 20% larger than page size.

### Option 2: 1.5x Scale (Larger - for small text)
If text is still not readable, uncomment this option in main.tex (lines 52-56):
```latex
\includegraphics[width=1.5\textwidth,height=1.5\textheight,keepaspectratio]{topic-declaration.png}
```
Makes image 50% larger - better for documents with small text.

### Option 3: Actual Size (No scaling)
If you want to use the original image size, uncomment this option (lines 58-62):
```latex
\includegraphics[scale=1.0]{topic-declaration.png}
```

## How to Change Options

1. Open `thesis/main.tex`
2. Find lines 47-62 (Topic declaration section)
3. Comment out current option by adding % at start of lines
4. Uncomment your preferred option by removing % from start of lines
5. Recompile

## Image Quality Tips

For best readability:
- Use high resolution (at least 1200 DPI for scanned documents)
- Save as PNG for better quality
- Ensure text is clear and sharp
- Remove shadows or distortions if scanned
- Use good lighting if taking photo

## Troubleshooting

### Text is not readable
- Try Option 2 (1.5x scale) in main.tex
- Or use a higher resolution source image
- Or edit the image to increase contrast

### Image is cut off
- Use `keepaspectratio` option (already included)
- Or reduce the scale factor (e.g., 1.0x instead of 1.2x)

### Image appears blurry
- Use PNG instead of JPG
- Increase source image resolution
- Ensure original scan/photo is sharp
