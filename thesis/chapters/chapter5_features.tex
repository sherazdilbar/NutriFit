\section{Dashboard}

The dashboard provides an overview of user's health and fitness data.

\begin{figure}[H]
\centering
\includegraphics[width=0.9\textwidth]{dashboard.png}
\caption{Main Dashboard}
\label{fig:dashboard}
\end{figure}

\textbf{Dashboard Components:}
\begin{itemize}
    \item \textbf{Quick Stats}: Health profile status, active goals, generated plans, water intake
    \item \textbf{Weekly Summary}: Total meals, workouts, average calories, active days
    \item \textbf{Streaks}: Consecutive days of meal and exercise logging with badges
    \item \textbf{Reminders}: Actionable alerts for meals, exercise, water, and goals
    \item \textbf{Recipe Suggestions}: Meal ideas combining safe foods
\end{itemize}

\textbf{Profile Information:}
\begin{itemize}

    \item Activity level: sedentary to very active

\section{Additional Features}

\subsection{Water Intake Tracking}
\begin{itemize}
    \item Track daily water consumption (glasses)
    \item Default goal: 8 glasses per day
    \item Progress bar visualization
    \item Quick add/remove buttons
\end{itemize}

\subsection{Favorites System}
\begin{itemize}
    \item Mark frequently used foods and exercises
    \item Quick access to favorites
    \item One-click add to logs
\end{itemize}

\subsection{Reminders}
\begin{itemize}
    \item No meal logged today (high priority)
    \item No exercise in 3 days (medium priority)
    \item Water intake below goal (low priority)
    \item Goal deadline approaching (high priority)
\end{itemize}

\subsection{Recipe Suggestions}
\begin{itemize}
    \item Combine protein, carbs, and vegetables
    \item Exclude allergen foods
    \item Calculate total calories
    \item 3-5 recipe suggestions
\end{itemize}
