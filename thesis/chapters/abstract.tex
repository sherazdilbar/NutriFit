\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis presents the design, implementation, and evaluation of NutriFit, a comprehensive web-based health and fitness tracking application. The system addresses the growing need for personalized health management tools by providing users with an integrated platform for tracking nutrition, exercise, and overall wellness goals.

The application features a robust architecture built on modern web technologies including Next.js 14, React 18, TypeScript, and Prisma ORM with SQLite database. The system implements intelligent algorithms for generating personalized diet and workout plans based on individual health profiles, incorporating the Harris-Benedict equation for calorie calculation and comprehensive safety checks for food allergens and exercise restrictions.

Key features include health profile management with BMI calculation, automated diet and workout plan generation, meal and exercise logging with validation, goal tracking with progress monitoring, weekly summaries, streak tracking, water intake monitoring, favorites system, smart reminders, and recipe suggestions. The application ensures user safety by excluding allergen-containing foods and restricting high-impact exercises for users with medical conditions such as heart disease, arthritis, and joint problems.

The system underwent comprehensive testing including unit tests for core calculations, integration tests for API endpoints, system tests for complete user workflows, and performance evaluation. Results demonstrate that the application meets all functional requirements with page load times under 3 seconds and API response times under 1 second, while maintaining compatibility across all major web browsers.

The responsive design ensures optimal user experience across mobile, tablet, and desktop devices. The application successfully demonstrates the practical application of full-stack web development principles, database design, RESTful API architecture, and modern software engineering practices.

\textbf{Keywords:} Health tracking, fitness management, web application, personalized recommendations, diet planning, workout planning, Next.js, React, TypeScript, Prisma ORM
